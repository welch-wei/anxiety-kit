# 焦虑急救箱

**在线访问：** https://welch-wei.github.io/anxiety-kit/

**定位：** 焦虑、恐慌发作时，3 秒内打开、60 秒内平复的即时工具。

## 核心功能

- **一键 SOS 急救**：发作时选择最适合的急救工具
- **4-7-8 呼吸法**：动画引导，3 轮循环
- **5-4-3-2-1 grounding**：感官接地练习
- **认知重构（CBT）**：区分想法与事实，记录灾难化想法
- **渐进式肌肉放松（PMR）**：8 组身体部位逐次放松
- **情绪倾倒**：不加评判地写下全部想法，一键倒空
- **睡眠仪式**：睡前 10 分钟放松流程，含呼吸与清单
- **每日预防计划**：降低焦虑发作风险的习惯追踪
- **危机评估**：识别自伤/自杀关键词，自动弹出求助热线
- **发作记录**：强度、症状、触发因素、平复状态、使用工具
- **趋势分析**：7 天/30 天焦虑强度曲线、诱因统计
- **求助热线**：整合全国 24 小时心理援助热线
- **本地存储**：所有数据存在用户浏览器，不上传服务器，隐私优先
- **Pro 7 天试用**：本地模拟，无需后端即可体验完整功能

## 目标用户

- 有焦虑、惊恐发作经历的人
- 高压职场人（互联网、金融、销售、管理）
- 学生、备考、求职人群
- 有睡眠问题、健康焦虑的人
- 心理咨询/精神科患者的辅助工具
- 企业 EAP 采购方、高校心理咨询中心、医院精神科

## 技术实现

- 纯前端单页 HTML，无后端，无服务器成本
- 数据本地存储（localStorage），隐私优先
- 使用 Chart.js 绘制趋势图与诱因图
- 使用 jsPDF 在前端生成 PDF 报告
- 部署在 GitHub Pages，免费、稳定、自动更新

## 支付对接方案

### 中国大陆
- **微信支付 JSAPI**：需注册微信商户号 + 服务号，H5 环境下可调用
- **支付宝手机网站支付**：需注册企业支付宝账号
- 当前版本为本地演示，真实支付需替换 `upgrade()` 函数

### 海外/出海
- **Stripe Checkout**：无需后端，直接跳转 Stripe 托管页面
- **Paddle / Lemon Squeezy**：适合个人开发者，税率处理更省心

### 快速变现 MVP
1. 在页面底部放置二维码收款（微信/支付宝个人收款码）
2. 用户付款后手动发送兑换码或开通 Pro
3. 验证可行性后，再接入正式支付 API
